허리를 펴세요

실제로는 이렇게 동작해요

시간은 예시예요. 타이머는 기본값인 앉기 50분, 휴식 10분으로 잡았어요.

  1. 14:00

    사이드패널을 열고 기준 자세를 저장해요

    툴바에서 TurtleShell 아이콘을 누르고 미리보기 가운데 카메라 버튼으로 감지를 시작하세요. 편하게 바로 앉은 다음 ‘현재 자세를 기준으로 설정’을 누르면 지금 자세가 기준이 돼요.

  2. 14:35

    영상을 보다가 고개가 앞으로 나와요

    귀가 기준보다 앞으로 나간 만큼 보던 탭이 어두워지고 흐려져요. 최대 6px까지 흐려지는데, 그쯤 되면 가운데에 ‘허리를 펴세요’가 뜨고 링크나 버튼도 눌리지 않아요.

  3. 14:36

    다시 바로 앉아요

    흐림이 바로 풀려요. 따로 누를 건 없어요.

  4. 14:50

    앉은 지 50분이 지났어요

    쉬는 시간 10분 동안 화면이 뒤로 살짝 눕혀져 있어요. 기울기는 사이드패널에서 바꿀 수 있어요.

  5. 15:00

    다시 앉는 시간이에요

    화면이 원래대로 돌아오고 50분 타이머가 다시 돌아가요.

이럴 땐 어떻게 돼요?

고개를 옆으로 돌리면요?

측정을 잠깐 멈춰요. 고개를 옆으로 기울이거나 몸을 돌렸을 때도 마찬가지고, 0.4초 넘게 그 상태면 흐림도 풀어요.

자리를 비우면요?

얼굴과 어깨가 하나도 안 보이면 바로 원래 화면으로 돌아가요.

화상 회의 중에는요?

Meet, Zoom, Teams처럼 웹페이지가 카메라를 켜면 감지를 멈춰요. 사이드패널의 ‘회의 사이트 자동 중지’로 끌 수 있어요.

지금 당장 화면을 봐야 하면요?

흐려진 화면 오른쪽 위의 ‘감지 끄기’를 누르면 바로 꺼져요. 클릭이 막혀 있을 때도 이 버튼은 눌려요.

카메라 영상은 어디로 가요?

아무 데도 안 가요. 분석은 브라우저 안에서 끝나고 영상은 저장하지 않아요. 사이드패널에 내 얼굴이 보이는 것도 싫으면 프라이버시 모드를 켜세요. 영상 대신 실루엣만 보여요.

설치

크롬 웹스토어 심사가 끝날 때까지는 압축 파일로 설치해요. 화면을 따라 하면 3분이면 끝나요.

dist.zip 다운로드

  1. dist.zip을 받아서 압축을 풀어요

    왼쪽 버튼으로 받은 파일을 풀면 dist 폴더가 생겨요. 크롬이 계속 이 폴더에서 불러오니까 지우지 말고 그대로 두세요.

    dist.zip → dist 폴더

    Windows 파일을 오른쪽 클릭 → ‘압축 풀기’  ·  Mac 파일을 더블클릭

  2. 확장 프로그램 페이지에서 개발자 모드를 켜요

    아래 주소를 복사해서 크롬 주소창에 붙여 넣고 Enter를 누르세요. 페이지 오른쪽 위의 개발자 모드 스위치를 켜면 돼요.

  3. ‘압축해제된 확장 프로그램 로드’를 눌러요

    개발자 모드를 켜면 왼쪽 위에 버튼 세 개가 생겨요. 첫 번째 버튼을 누르고, 1번에서 푼 dist 폴더를 고른 뒤 ‘폴더 선택’을 누르세요.

    zip 파일은 고를 수 없어요. 압축을 푼 dist 폴더를 고르세요. 안에 manifest.json이 보이면 맞는 폴더예요.

  4. 이 카드가 보이면 설치 끝, 툴바에 고정해요

    TurtleShell 카드가 생기면 설치된 거예요. 주소창 오른쪽의 퍼즐 조각 아이콘을 누르고 TurtleShell 옆 핀을 누르면 아이콘이 툴바에 계속 보여요.

    주소창1
    TTurtleShell2
    퍼즐 조각 → TurtleShell 옆 핀

  5. 카메라를 켜고 기준 자세를 저장해요

    툴바의 TurtleShell 아이콘을 누르면 오른쪽에 사이드패널이 열려요. 미리보기 가운데 카메라 버튼을 누르고 카메라를 허용하세요. 그다음 편하게 바로 앉아서 현재 자세를 기준으로 설정을 누르면 끝이에요.

    설치 전에 열어 둔 탭은 한 번 새로고침해야 화면 효과가 나타나요.
